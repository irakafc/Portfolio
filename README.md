### 🔹 Telecom Customer Usage Analysis (ConnectaTel)

**🔍 Problem**  
How do telecom customers actually use services like calls and messages across regions?  

**⚙️ Action**  
Built a full Python data pipeline using **Pandas and NumPy**, integrating multiple datasets (users, plans, usage), cleaning data, and performing EDA. Detected outliers and segmented customers by age, plan, and geography.  

**📈 Result**  
Identified underutilized and overutilized plans, revealing opportunities for pricing and product optimization.  

**🛠️ Skills:** Python | Pandas | EDA | Data Cleaning | Segmentation  

---

### 🔹 Behavioral Drivers in E-commerce (NovaRetail+)

**🔍 Problem**  
What behavioral factors truly drive revenue in e-commerce platforms?  

**⚙️ Action**  
Performed correlation analysis using Python, applying Pearson, Spearman, and Cramér’s V. Built heatmaps and scatterplots to analyze relationships between behavior and revenue.  

**📈 Result**  
Found that engagement metrics (visits, purchases) are stronger revenue drivers than demographic variables.  

**💡 Insight:** Correlation does not imply causation—context is essential in interpretation.  

**🛠️ Skills:** Python | Statistics | Correlation Analysis | EDA  

---
